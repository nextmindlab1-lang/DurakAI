Durak AI Assistant

Android-помощник для карточной игры «Дурак Онлайн».

Возможности проекта

- Android-приложение на Kotlin.
- Основа для плавающего окна поверх игры.
- Подготовка к распознаванию карт и анализу ходов.
- Поддержка правил подкидного и переводного дурака.

Статус

Это прототип. Автоматическое распознавание карт и подсказки в реальном времени ещё требуют реализации.
